1. Почему heroesCreated должно быть статическим?
Потому что это общее для класса значение.

2. Почему name, health и level не должны быть статическими? 
Потому что они индивидуальны для каждого из героев.

3. Почему printHeroesCreated() можно вызвать без создания объекта? 
Потому что это статический метод.

4. Можно ли из статического метода напрямую обратиться к нестатическому полю name? Почему? 
Нельзя, т.к. в этом случае будет ошибка компиляции. Статический метод вызывается без объекта, а name принадлежит объекту.

5. Почему проект перестанет компилироваться если пометить класс Hero модификатором final?
Потому что final не предусматривает классов-наследников, его нельзя расширить.

6. Почему переменные имеют тип Hero, но при этом вызываются версии метода attack() из конкретных наследников?
Потому что вызывается метод того реального объекта, который хранится в переменной, а не того типа, которым объявлена переменная.

7. Почему переменная knight имеет модификатор final но ее поля могут быть изменены?
Потому что final для переменной означает, что нельзя нельзя присвоить другой объект. 
Но сам объект остаётся изменяемым, если его поля не объявлены final.
