1. Нужно ли было в принципе писать свой собственный генератор с фамилиями?
Было бы проще использовать генератор из datafaker?

Если нам не нужны конкретные данные в массиве, то проще использовать генератор. Если есть какие-то нюансы, которые генератор не учитывает - стоит подготовить собственный массив данных.

2. Какая из двух библиотек из этого задания может больше пригодится при написании автотестов - jfiglet или datafaker?

Это точно datafaker, т.к. имеем дело с заполнением данных по ФЛ, юрлицам.

3. Каким образом JAR-файлы этих библиотек попали к нам в проект?

Указанные в файле build зависимости скачиваются с помощью интернета с внешнего хранилища.
